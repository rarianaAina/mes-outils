MES OUTILS - le tableau de bord de mes outils personnels
=======================================================

LA BULLE
--------
Une bulle violette flotte sur l'écran, au-dessus des autres fenêtres, sans
bouton dans la barre des tâches. Elle démarre avec Windows (raccourci dans le
dossier Démarrage : touche Windows + R, taper shell:startup ; supprimer
« Mes outils » pour qu'elle ne démarre plus toute seule).

  Clic              ouvre le tableau de bord (ou le ramène devant s'il est ouvert)
  Glisser           la déplace ; elle revient au même endroit la fois suivante
  Clic droit        accès direct : Note rapide, Mails, Agenda, Notes, vos
                    outils, Serveurs Odoo (démarrer, arrêter, ouvrir),
                    Masquer 15 minutes, Quitter la bulle
  Pastille verte    nombre de serveurs Odoo en marche (en haut à droite)
  Pastille corail   nombre de mails non lus (en haut à gauche)
  Au repos          un peu transparente ; pleine quand la souris passe dessus

Si la bulle a été quittée : raccourci « Mes outils » du Bureau, ou
« Mes outils.bat » dans ce dossier.

Pastille rouge (en bas)  tests GitHub (Actions) en échec

Le tableau de bord s'ouvre dans une fenêtre Edge sans barre d'adresse. La
fermer (ou la croix) ne coupe rien : la bulle reste là.

Menu à gauche : les applications actives, rangées en « Au quotidien »,
« Clients et ventes », « Organisation », « Développement », « Petits
outils ». Ctrl + K (ou « Rechercher… » en haut) : aller à une application,
lancer un outil ou une action au clavier. Bouton soleil/lune : thème clair,
sombre ou automatique (comme Windows).


PREMIER LANCEMENT ET APPLICATIONS
---------------------------------
Au premier lancement, trois étapes : votre prénom et la langue, votre métier
(freelance, assistant virtuel, assistant de direction, développeur ou
personnalisé), puis les applications à garder (cochées d'après le métier,
modifiables).

Page « Applications » (menu, en bas) : un interrupteur par application.
Désactiver une application la retire du menu, de l'Accueil, de Ctrl + K et
de la bulle ; ses données restent et reviennent quand on la réactive.
« Repartir d'un métier… » recoche les applications d'un métier.


LES OUTILS
----------
- Clic sur une tuile : l'outil s'ouvre.
  Une « Appli locale » est démarrée si elle ne tourne pas, puis ouverte dans
  sa fenêtre.
- Modifier : les tuiles se mettent à bouger ; pour modifier, pour retirer,
  « Ajouter un outil » pour en créer un. Types possibles :
    Dossier, Fichier / programme (.exe, .bat…), Page web,
    Appli locale (un outil avec son propre petit serveur : adresse, port et
    commande de démarrage).
- Tout est enregistré dans outils.json (modifiable aussi à la main).


LES ONGLETS
-----------
Accueil   « Aujourd'hui » (rendez-vous du jour et du lendemain, notes
             épinglées, mails non lus) et une carte par application active
             qui a quelque chose à signaler (tâches du jour, relances,
             factures impayées, budget, échéances, documents à renouveler,
             prochaine réunion), puis vos outils.

Tâches    Titre, description, échéance (heure facultative), priorité,
             étiquettes, client, sous-étapes à cocher, répétition (chaque
             jour, semaine ou mois). Vue Liste (en retard, aujourd'hui, cette
             semaine, plus tard) ou Tableau (À faire, En cours, Fait, par
             glisser-déposer). Ajout rapide : taper le titre puis Entrée.
             Rappel par la bulle pour les tâches avec une heure.

Missions  Offres freelance et télétravail (Remotive, Remote OK, Himalayas,
             Jobicy, We Work Remotely), lues deux fois par jour au plus.
             Recherches enregistrées : domaines, types, zones, niveau, salaire
             minimum, mots importants / utiles / à éviter, score minimum.
             Chaque offre a un score ; Postuler (message ou modèle), Ajouter
             l'entreprise aux contacts, Masquer. Onglet Candidatures : à voir,
             postulé, entretien, refus, retenu, relance (tâche). Liens vers
             Malt, Codeur.com, ComeUp, Upwork, LinkedIn, Indeed.

Contacts  Personnes et entreprises : coordonnées, statut (prospect, client,
             ancien, fournisseur), étiquettes, historique daté (appel, mail,
             rendez-vous, note), relance à une date (rappel par la bulle).
             Import et export CSV (Excel) : une fiche déjà présente est
             complétée, jamais écrasée.

Devis et factures
             Première fois : votre entreprise (nom, adresse, identifiants,
             logo, TVA, devise, préfixes de numérotation). Au Canada : régime
             « Canada » et province (TPS et TVQ, TVH, TPS et TVP), numéros
             d'inscription imprimés, case « Taxable » par ligne, dollar
             canadien. Devis, factures et
             avoirs : lignes, plusieurs taux de TVA, remise ; numéro attribué
             à l'émission, à la suite, remis à 1 chaque année ; un document
             émis n'est plus modifiable (avoir pour corriger). Devis accepté
             = transformé en facture. Paiements partiels, retard signalé par
             la bulle, PDF (dans Documents\Mes outils\Factures\<année>),
             envoi par mail, import des heures de Temps, export CSV.

Dépenses  Tableau de bord du mois (budget, reste par jour, projection),
             dépenses par mois, charges fixes ajoutées seules chaque mois,
             budget, épargne (reprise possible en cas de dépassement),
             statistiques, catégories. Dépense professionnelle : client,
             statut (à rembourser, remboursée, refacturée), justificatif
             photo ou PDF ; onglet Notes de frais ; export CSV.

Documents Un classeur de vos documents importants : le fichier reste où il
             est (copie facultative dans Documents\Mes outils\Classeur).
             Type, client ou projet, étiquettes, date d'expiration avec
             rappel. Un fichier déplacé est signalé « Introuvable » avec
             « Retrouver… ». « Retirer de la liste » ne supprime jamais le
             fichier.

Réunions et déplacements
             Réunions : participants, ordre du jour, notes, décisions,
             actions (transformées en tâches), compte rendu préparé dans un
             mail, ajout à l'agenda. Déplacements : trajets, hébergement,
             documents, liste à emporter, feuille de route imprimable.
             Rappels : 15 minutes avant une réunion, la veille d'un départ.

Échéances Abonnements, contrats, assurances, noms de domaine, loyers :
             montant, périodicité, prochaine date, reconduction tacite et
             préavis. Rappel avant l'échéance et avant la date limite de
             résiliation. « Payé » passe à la période suivante. Coût mensuel
             et annuel par catégorie, export CSV.

Modèles de messages
             Réponses types, relances, confirmations : textes avec variables
             ({prenom}, {montant}…) remplies au moment de l'utilisation, avec
             un contact choisi dans Contacts. Copier, ouvrir dans un mail,
             ou bouton « Modèle » dans la fenêtre Nouveau mail. Favoris,
             catégories, import et export.

Mails     Votre boîte mail : Gmail, Yahoo, iCloud, Zoho, Fastmail, GMX,
             OVH, Orange, Free, La Poste, ou « Autre » (serveurs IMAP/SMTP
             saisis à la main). Outlook/Hotmail : pas encore (Microsoft exige
             une autre méthode de connexion). Reçus, envoyés, recherche,
             lecture, répondre, transférer, nouveau mail. Première fois : le
             guide du fournisseur est affiché dans l'onglet (mot de passe
             d'application ou mot de passe habituel) ; il est rangé dans le
             coffre de Windows (Gestionnaire d'identification >
             Informations d'identification Windows > « MesOutils:mail:… »).
             Les images distantes des mails sont bloquées (elles servent à
             savoir si vous avez ouvert le mail) : bouton « Afficher les images ».
             Les pièces jointes sont listées ; on les ouvre depuis le webmail.
             Bouton : déconnecter (le mot de passe est retiré du coffre).

Notes     Notes en cartes colorées ou listes à cocher, épingle , recherche,
             rappel à une date et une heure. Enregistrement automatique
             pendant la frappe. Dans une liste : Entrée = élément suivant,
             Retour arrière sur un élément vide = le retirer.

Agenda    Vue semaine (cliquer sur un créneau pour créer un rendez-vous) et
             vue mois. Rappel par la bulle : à l'heure, 5/15/30 min, 1 h avant,
             la veille.
             Déplacer : glisser le rendez-vous (vue semaine : autre jour ou autre
             heure, par pas de 15 min ; vue mois : autre jour).
             Dupliquer : Ctrl + glisser, ou bouton « ⧉ Dupliquer » du rendez-vous
             (la copie s'ouvre pour choisir le jour).

Mots de passe
             Coffre chiffré (AES-256-GCM, clé tirée du mot de passe maître par
             scrypt). Le mot de passe maître n'est enregistré nulle part :
             S'IL EST OUBLIÉ, LE COFFRE EST PERDU. Notez-le sur papier.
             Le coffre se verrouille après 5 minutes sans utilisation (ou ).
             copie le mot de passe : il est effacé du presse-papiers après
             30 secondes et n'entre pas dans l'historique Win + V. l'affiche
             15 secondes. génère un mot de passe solide. Catégories, note
             chiffrée par entrée, recherche.
             Fichier : donnees\coffre.json (illisible sans le mot de passe
             maître) ; copie précédente : coffre.json.bak.

SSH       Une clé par serveur, posée en un clic : « ＋ Nouveau serveur »,
             saisir le nom, l'adresse, le port, l'utilisateur et le mot de
             passe. L'outil crée la clé (sans phrase de passe), la dépose sur
             le serveur avec le mot de passe, puis vérifie la connexion. Le mot
             de passe ne sert qu'à cette fois : il n'est enregistré nulle part.
             Ensuite, dans un terminal : « ssh <nom-court> » (affiché sur la
             carte, clic = copie). teste la connexion, ouvre un terminal
             sur le serveur, retire la clé du serveur puis de ce PC.
             Fichiers : clés dans %USERPROFILE%\.ssh (mesoutils_<nom-court>),
             raccourcis dans %USERPROFILE%\.ssh\config (blocs « Mes outils »),
             liste dans donnees\ssh.json (aucun secret).

GitHub    Tous vos dépôts (publics, privés, ceux de vos organisations),
             avec recherche et filtre (privés, publics, sur ce PC ou non).
             Connexion une seule fois : « Connecter GitHub » affiche un code
             de 8 caractères (déjà copié) et ouvre github.com/login/device ;
             collez-le, cliquez sur Authorize, c'est fini. L'accès est rangé
             dans le coffre de Windows (« MesOutils:github ») ; le retire.
             Dossiers de projets : l'outil y repère les dépôts déjà sur ce
             PC (le dossier et ses sous-dossiers directs) et y clone les
             nouveaux. Pour chaque dépôt : GitHub, puis Dossier et
             VS Code s'il est sur ce PC, sinon Cloner.
             ＋ Nouveau dépôt : choisir un dossier, « Vérifier le contenu »
             (nombre de fichiers, .gitignore respecté, fichiers sensibles
             comme .env ou clés signalés, fichiers de plus de 100 Mo
             refusés), puis « Créer et envoyer » (privé par défaut).

Projets   Les projets trouvés dans vos dossiers de projets (Réglages), avec
             leur type (Node, Python, Django, Docker, Odoo…). Pour chacun :
             dossier, VS Code, terminal, site local.
             Commandes (serveurs de dev) : proposées d'après le projet
             (npm run dev, manage.py runserver, docker compose up…),
             modifiables ; démarrer, arrêter (seulement ce que Mes outils a
             lancé), journal (donnees\journaux).
             Git : à envoyer, à récupérer, modifié ; « Tout vérifier »
             fait un git fetch de tous les projets.
             .env : sauvegardé dans le coffre chiffré (catégorie « env »),
             restauré en un clic (le coffre doit être ouvert).

GitHub    (suite) Pull requests (les vôtres, celles où votre relecture est
             demandée), issues qui vous sont assignées, état des GitHub
             Actions des dépôts récents et de ceux de ce PC.

Ports     Les ports en écoute et le programme qui les occupe ; recherche
             d'un port ; « Arrêter » après confirmation (les processus système
             et Mes outils lui-même sont protégés).

Docker    Conteneurs groupés par projet compose : démarrer, arrêter,
             redémarrer, supprimer, journal, ports cliquables.

Testeur d'API
             Méthode, adresse, en-têtes, corps, authentification ; réponse
             mise en forme ; historique (les secrets n'y sont jamais
             enregistrés), requêtes enregistrées, copie en cURL.

Boîte à outils
             JWT, Base64, JSON, horodatage, UUID, expressions régulières,
             encodage URL, empreintes SHA, couleurs. Rien ne quitte la page.

Extraits  Vos commandes et bouts de code favoris : un clic = copié (aussi
             depuis le clic droit sur la bulle).

Presse-papiers
             Les 50 derniers textes copiés, gardés EN MÉMOIRE seulement
             (effacés à la fermeture). Les mots de passe copiés depuis le
             coffre n'y entrent pas. Pause possible.

Temps     Chrono par projet (un seul à la fois), Pomodoro (la bulle
             prévient à la fin de chaque période), sessions par jour, semaine
             ou mois, totaux par projet, export CSV pour Excel.

Réglages  Prénom, langue (français / anglais), thème, métier et
             applications (bouton « Choisir mes applications »), dossiers de
             projets, démarrage avec Windows, raccourci sur le Bureau, mise à
             jour.

WhatsApp  La tuile ouvre WhatsApp Web dans sa propre fenêtre (votre
             WhatsApp habituel : scannez le QR code une fois avec le téléphone).


LES RAPPELS
-----------
À l'heure dite, une carte apparaît à côté de la bulle (avec un son), et la
bulle frétille : « Ouvrir » (affiche la note ou l'agenda), « Plus tard »
(dans 10 minutes) ou « OK ». Les rappels manqués pendant que le PC était
éteint apparaissent au démarrage (jusqu'à 2 jours de retard).
Les applications actives ajoutent leurs propres rappels : tâche à l'heure,
contact à relancer, facture en retard, budget dépassé, document qui expire,
échéance, réunion et départ en déplacement.


LES SERVEURS ODOO
-----------------
Facultatif. Ce sont ceux d'un gadget « Serveurs Odoo » externe
(gestion_serveurs.py), dont le chemin est donné dans outils.json, clé
« serveurs_odoo » > « gadget ». Sans gadget, la section est simplement vide.
Même liste, mêmes commandes, mêmes journaux que le gadget. Pastille verte = en marche, orange =
démarrage, grise = arrêté, rouge = port pris par un autre programme.
  Démarrer   Arrêter   ↗ Ouvrir dans le navigateur   Journal
Une base marquée « référence » demande une confirmation avant d'être
démarrée. Pour ajouter un serveur ou voir les comptes d'une base :
bouton « Gadget complet ».


LES FICHIERS
------------
  outils.json          la liste des tuiles, votre prénom (salutation) et votre
                       adresse Gmail ; créé depuis outils.exemple.json au premier
                       lancement, jamais envoyé sur GitHub
  bulle.json           la position de la bulle
  donnees\notes.json   vos notes (copie de la version précédente : notes.json.bak)
  donnees\agenda.json  vos rendez-vous (copie : agenda.json.bak)
  outil\web\           les onglets Notes, Agenda et Mails (notes.js, agenda.js, mails.js)
  outil\donnees.py     enregistrement des notes, de l'agenda et des rappels
  outil\mail.py        la connexion Gmail (IMAP pour lire, SMTP pour envoyer)
  outil\coffre.py      le coffre à mots de passe
  outil\github.py      l'onglet GitHub (connexion, dépôts, clonage, envoi, PR, Actions)
  outil\<nom>.py et outil\web\<nom>.js
                       une application chacune (taches, contacts, factures,
                       depenses, documents, echeances, reunions, modeles,
                       projets, ports, temps, reglages…) ; leurs données
                       dans donnees\<nom>.json (fichiers joints dans
                       donnees\<nom>\) ; pour en ajouter une : docs\MODULES.md
  outil\config.py      lecture et écriture d'outils.json et du dossier donnees
  outil\coffre_windows.py  lecture et écriture dans le coffre de Windows
  tests\               tests automatiques : python -m unittest discover -s tests

Sécurité : le serveur n'écoute que sur ce PC et refuse tout ordre qui ne
vient pas de la page elle-même (une page web ouverte dans le navigateur ne
peut pas lui parler).
  outil\bulle.py       la bulle (elle fait aussi tourner le serveur du tableau de bord)
  outil\hub.py         le petit serveur local (http://127.0.0.1:8760, ce PC seulement)
  outil\hub.html       la page
  outil\hub.log        les erreurs éventuelles
  outil\mes_outils.ico l'icône des raccourcis

Installation sur un autre PC : le plus simple est Mes-outils-Setup.exe (page
Releases du dépôt GitHub) : Python et tout le nécessaire sont inclus, sans
droits administrateur. Le programme va dans %LOCALAPPDATA%\Programs\Mes outils,
les réglages et données dans %APPDATA%\Mes outils (repris automatiquement
d'une ancienne copie « code source » au premier lancement).
Depuis le code source : installer.bat (vérifie Python, installe les
bibliothèques, crée les raccourcis, lance la bulle).
« Mes outils.bat » utilise pythonw du PATH, ou le Python indiqué dans la
variable d'environnement MES_OUTILS_PYTHON. Bibliothèques nécessaires :
pip install -r requirements.txt


SOUS LINUX (Ubuntu 24.04 et autres)
-----------------------------------
Mes-outils-x86_64.AppImage (page Releases du dépôt GitHub) : un seul
fichier, sans installation ni droits administrateur. Le rendre exécutable
(clic droit > Propriétés > « Exécutable comme programme », ou
chmod +x Mes-outils-x86_64.AppImage), puis double-clic.

  Bulle et icône    la bulle, plus une icône en haut à droite de l'écran
                    (même menu). Sous GNOME avec Wayland, la bulle peut
                    passer derrière les autres fenêtres : Réglages > Linux
                    permet de choisir bulle et icône, bulle seule ou icône
                    seule.
  Rappels           la carte à côté de la bulle et une notification du bureau.
  Données           ~/.config/mes-outils
  Secrets           mots de passe des mails et accès GitHub dans le trousseau
                    du bureau (GNOME Keyring, KWallet).
  Navigateur        Google Chrome ou Chromium pour la fenêtre sans barre
                    d'adresse et les PDF des factures (sudo snap install
                    chromium) ; sinon le navigateur par défaut.
  Fichiers          fenêtres de choix par zenity (ou kdialog sous KDE).
  Menu, session     entrée « Mes outils » dans le menu des applications
                    (~/.local/share/applications) ; démarrage avec la session
                    (~/.config/autostart), réglable dans Réglages.
  Mise à jour       automatique : la nouvelle AppImage remplace l'ancienne.

Depuis le code source : sudo apt install python3-tk zenity, puis
pip install -r requirements.txt et python3 outil/bulle.py.
